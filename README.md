# Dashboard do Clima
Projeto de um site para consultar o clima de diferentes cidades.
O usuário digita o nome de uma cidade e o site mostra a temperatura, umidade e velocidade do vento.

## Tecnologias
* HTML
* CSS
* JavaScript
* API Open-Meteo

## O que foi usado no projeto
* Manipulação do DOM
* Eventos em JavaScript
* Fetch API
* Async/Await
* Consumo de API
* JSON

## Como usar
Baixe ou clone o repositório e abra o arquivo `index.html` no navegador.
